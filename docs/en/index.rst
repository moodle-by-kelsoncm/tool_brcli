Overview - moodle-tool_brcli
=============================

**moodle-tool_brcli** (**BrCLI - Backup & Restore Command-Line Interface**) is an administrative tool plugin (`admin/tool`) for Moodle that enables batch backups and restores of **entire course categories** via the command line.

Key Features
------------

- **Batch Backup by Category**: Back up all courses belonging to a specific category with a single command.
- **Batch Restoration**: Restore a batch of `.mbz` backup files into a designated destination category.
- **Native CLI Integration**: Runs in the background via PHP CLI without hitting web browser timeout limits.
